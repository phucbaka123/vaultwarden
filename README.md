# vaultwarden
Self-hosted password manager built with Vaultwarden, Docker, Nginx Proxy Manager, and Tailscale. Provides a secure and private alternative to Bitwarden Cloud using end-to-end encryption and local data storage.

A secure, private password manager running on Ubuntu using **Docker**, **Nginx Proxy Manager**, and **Vaultwarden**.

Features
- Private encrypted access via **Tailscale**
- HTTPS and global access via **Cloudflare Tunnel**
- Reverse proxy management through **Nginx Proxy Manager**
- Docker Compose deployment for easy setup and updates
- Works with Bitwarden mobile & desktop apps

Tech Stack
Docker • Nginx • Vaultwarden • Tailscale • Cloudflare • Linux

What I Learned
- Docker networking & volumes  
- Reverse proxy configuration  
- VPN-based access control with Tailscale  
- Managing SSL/TLS through Cloudflare  
- Securely exposing local services to the web
